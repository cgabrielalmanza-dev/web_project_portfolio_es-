# Proyecto del Sprint 4 - Portafolio

Descripción del proyecto:
Este proyecto consiste en el desarrollo de un sitio web de portafolio personal. El objetivo es presentar de manera profesional la información de una desarrolladora web, sus habilidades técnicas, proyectos realizados y medios de contacto.

Funcionalidades:
Presentación personal con fotografía, nombre y descripción profesional.
Sección de habilidades y herramientas de desarrollo web.
Galería de proyectos destacados con imágenes y descripciones.
Enlaces a repositorios de GitHub y demostraciones de proyectos.
Sección de contacto con correo electrónico y redes sociales.
Efectos visuales :hover en enlaces e íconos.
Diseño responsivo adaptado a computadoras, tablets y teléfonos móviles.

Tecnologías:
HTML5: estructura semántica del sitio web.
CSS3: estilos, colores, tipografías y distribución de elementos.
Git: control de versiones del proyecto.
GitHub: almacenamiento del repositorio y publicación del sitio web.
Figma: Brief como referencia visual para implementar el diseño.

Técnicas de desarrollo:
Flexbox para organizar y alinear elementos.
CSS Grid para distribuir las tarjetas de proyectos y los íconos.
Media Queries para adaptar el diseño a diferentes resoluciones de pantalla.
Diseño responsivo para resoluciones de 320 px, 768 px y 1440 px.
Pseudoclase :hover para agregar interactividad visual.
Uso de fuentes personalizadas Open Sans y Archivo Black mediante @font-face.
Organización de archivos: index.html, styles.css, .editorconfig, .gitignore, .prettierignore, folder images para las imágenes y folder fonts para las fuentes.
